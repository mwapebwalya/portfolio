# Mwape Bwalya | Portfolio

Personal portfolio of **Mwape Bwalya**, a 3rd-year Software Engineering student at Zambia University College of Technology (ZUT) in Ndola.

- **Live Site**: [https://mwapebwalya.github.io](https://mwapebwalya.github.io)
- **GitHub**: [github.com/mwapebwalya](https://github.com/mwapebwalya)

## About

I have a background in Multimedia & Graphic Design that gives me a strong eye for user experience and visual systems. I'm currently building toward full-stack expertise, with a focus on clean Python automation, responsive web interfaces, and reusable UI component systems.

This portfolio showcases production-ready modules and interfaces I've designed and built, including:

- Web Development Portfolio
- Python Data & Automation (ETL + scheduling modules)
- UI Component System
- Graphic Design & Branding systems
- Campaign & Print Design
- Lost & Found Student Management platform
- Multilingual Translator module

## Tech Stack

- **Frontend**: HTML5, CSS3 (with custom design system), JavaScript
- **3D Background**: Three.js
- **Typography & Icons**: Fira Code + Inter (Google Fonts), Font Awesome
- **Deployment**: GitHub Pages (single-file static site)

All visuals are built with pure CSS — no external image dependencies.

## Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/mwapebwalya/mwapebwalya.github.io.git
   cd mwapebwalya.github.io
   ```

2. Open `index.html` directly in your browser.

That's it — no build step required.

## Deployment

This site is deployed automatically via **GitHub Pages**:

- Repository name must be `mwapebwalya.github.io` for the root domain.
- Push changes to the `main` branch.
- GitHub Pages is configured to serve from the root.
