```bash

git clone https://github.com/mwapebwalya/mwapebwalya.github.io.git
cd mwapebwalya.github.io

# Open directly in browser
open index.html          # macOS
```

## 🚢 Deployment

This portfolio is optimized for **GitHub Pages** with zero configuration.

### Recommended Setup (for clean URL)

1. Create a new repository on GitHub named exactly:  
   **`mwapebwalya.github.io`**

2. Push the contents of this folder to the `main` branch.

3. Go to **Settings → Pages** in your repo:
   - Source: Deploy from a branch
   - Branch: `main`
   - Folder: `/ (root)`
   - Save

Your site will be live at `https://mwapebwalya.github.io` within a minute.

### Quick Deploy Commands (after creating the repo)

```bash
git remote add origin https://github.com/mwapebwalya/mwapebwalya.github.io.git
git branch -M main
git add .
git commit -m "Initial portfolio deployment"
git push -u origin main
```

Then enable GitHub Pages as described above.
